# 使用体验优化计划

日期：2026-10-16。状态：已实施并完成批量验证。

目标是减少操作步骤、等待时的不确定性和误操作。以下保留需求及验收标准，实际交付和验证边界见文末实施记录。

## 约束

- 保留固定四标签：两个本地、两个 WebDAV；WebDAV 共用一个连接，各标签独立保存目录、滚动、搜索、排序和视图。
- 本地默认目录为 `/storage/emulated/0`；保留授权入口、路径边界和文件版本检查。
- 普通页面显示系统栏，工具栏始终可见；图片和视频按各自规则管理浮动控件与全屏。
- 搜索继续使用工具栏按钮打开的悬浮弹窗，只筛选当前目录；关闭保留查询，清空解除筛选。
- 保留多选、跨存储复制和移动、删除确认、完整传输校验、取消清理和错误恢复。
- 保留音轨、内嵌及外挂字幕、倍速、旋转和解码入口。无 Range 时提示拖动限制，并提供受容量、空间和取消约束的本地下载播放选项。

## 优化项目

### U01：启动与位置恢复

- 启动恢复上次活动标签、目录和滚动位置，避免每次从根目录重新寻找文件。
- 首次使用通过现有标签引导授权或配置连接，不增加“两文件夹”首页，不改变四标签导航。
- 恢复目录失效时解释原因，提供返回可访问目录、重新授权或编辑连接的入口。

验收：冷启动、旋转和 Activity 重建后位置恢复正确；失效目录不导致空白页或循环重试。

### U02：统一文件操作

- 将 New folder、New text 和 Storage access 做成工具栏按钮，分别用于新建文件夹、新建文本和存储授权；根据当前存储类型、权限及忙碌状态决定是否可用。
- 短按打开，长按进入多选；选中后集中在底部操作栏提供复制、移动、删除和更多操作。
- 重命名、属性和使用其他应用打开统一放入文件菜单，减少重复入口。
- 根据权限、选择数量和忙碌状态显示或禁用操作，并让不可用原因容易理解。

验收：单选和多选的操作位置一致；切换标签清除旧选择；不能对已经变化的文件执行过期操作。

### U12：路径按钮与直接跳转

- 当前路径显示为可点击按钮，长路径可省略显示；点击后打开悬浮文本编辑弹窗，并填入当前完整目录路径。
- 用户可以编辑或粘贴路径，使用“跳转”按钮或键盘确认直接打开目录；提供取消操作，取消不改变当前目录和滚动位置。
- 本地输入文件系统目录路径；WebDAV 输入当前连接命名空间内的目录路径，不要求输入服务器 URL，也不允许借此更换服务器。
- 跳转复用现有目录导航和请求取消逻辑，仅更新当前活动标签；成功后保存浏览位置，旧目录请求不得覆盖跳转结果。
- 提交前校验路径格式及存储边界。本地保留权限和符号链接检查，WebDAV 通过 DavPaths 校验及编码；支持空格、加号和中文，不把用户输入当成已编码 URL。
- 路径无效、超出边界、不存在、指向文件或无访问权限时显示明确错误，保留输入便于修改；跳转失败保留原目录内容，并提供重试。
- 已选择 SAF 目录时，通过 provider 验证目录归属，不通过拼接或猜测 document ID 将文件系统路径转换成文档 URI；无法解析的路径明确提示不支持直接跳转。

验收：工具栏三个按钮可访问；路径按钮能打开编辑弹窗，键盘确认与按钮提交行为一致；覆盖本地和 WebDAV 有效路径、特殊字符、根目录边界、权限失败、取消、快速连续跳转和标签切换。横屏与大字体下弹窗和确认按钮均可操作。

### U03：减少确认与干扰

- 删除保留一次明确确认，展示数量、永久删除含义和目录影响。
- 复制和移动采用不覆盖策略，重名项安全跳过，并在结果中说明。
- 普通成功操作使用轻量反馈，不再追加成功弹窗；重要失败保留可查看的错误信息。

验收：常用操作不出现重复确认；跳过和失败不会被当成成功，用户能找回结果。

### U04：传输进度与结果

- 持久底部状态条显示当前文件、完成项数、阶段和真实字节进度。
- 总量未知或服务端内部 COPY/MOVE 时使用不确定进度，不用文件数量伪造字节百分比。
- 将已完成、失败、跳过、取消和未处理项集中到一个详情面板，提供针对失败或剩余项的重试入口。
- 取消后说明已经完成的部分；服务端操作结果不明确时先核对两端状态，再允许安全重试。
- 关闭搜索弹窗或切换标签不丢失剪贴板与传输状态。

验收：结果分类与实际文件一致；重试不重复处理成功项，不覆盖目标，不盲目再次删除源文件。

### U05：搜索体验

- 打开搜索弹窗后自动聚焦输入框，输入即时筛选当前目录。
- 关闭弹窗保留结果，浏览页面显示筛选摘要和清空入口。
- 无匹配结果时区分“目录为空”和“搜索无结果”，提供清空查询操作。

验收：连续输入和快速切换标签不会显示旧结果；搜索、排序和视图状态按标签独立恢复。

### U06：空状态与错误恢复

- 空目录提供新建文件夹和返回上级等适用操作。
- 网络错误提供重试和编辑连接；权限错误提供重新授权。
- 有现有列表时采用局部加载反馈，刷新失败保留可用内容并注明状态。
- 错误使用可理解的文字和明确下一步，不暴露密码或认证头。

验收：断网、认证失败、权限撤销和目录消失均有恢复路径；旧请求不能覆盖新目录。

### U07：简化媒体默认界面

- 默认突出返回、播放暂停、进度和更多；音轨、字幕、速度、解码等集中到更多菜单。
- 画面水平滑动预览进度，松手后跳转；移除长按倍速手势，保留菜单倍速与旋转能力。
- 不支持拖动时在进度区域解释原因，并提供符合约束的本地下载播放入口。
- 退出视频后恢复普通系统栏，后台暂停并可靠保存位置。

验收：音视频播放、拖动、倍速、音轨、字幕、旋转及后台恢复均正常；Surface 和代理资源正确释放。

### U08：图片浏览减少干扰

- 返回、文件名和删除浮动栏贴近状态栏下方，仅处理一次顶部间距。
- 单击显示或隐藏控件，不改变图片视口；保留左右滑动、缩放和 GIF。
- 删除确认后按路径确定当前图片和相邻图片，最后一张删除后显示清晰的结束状态。

验收：隐藏控件不使图片跳动；连续滑动及删除不会误操作相邻文件；删除后缓存正确失效。

### U09：统一反馈

- 目录加载使用局部指示器，传输使用持续可见的状态入口。
- 短暂消息仅用于一般反馈；需要用户处理的错误保留在页面或详情面板。
- 统一按钮名称、阶段名称、取消状态和错误文案，避免同一操作多种叫法。

验收：用户无需依赖易消失的 Toast 判断操作结果；加载、完成和失败状态清楚可辨。

### U10：可访问性

- 为图标提供准确的文字描述，说明长按多选和滑动调整播放进度等手势。
- 点击目标至少 48 dp，支持系统字体放大和屏幕阅读器。
- 不仅依靠颜色表达选中、失败或禁用状态；长文件名允许查看完整内容。

验收：大字体和横屏下关键按钮可操作；TalkBack 能识别文件、选择状态、进度及主要操作。

### U11：外挂字幕加载

第一阶段：同目录发现、双来源加载、可靠切换和时间偏移。

- 打开视频时优先复用已有目录列表，查找同目录、同名的 `.srt`、`.ass`、`.ssa`、`.vtt` 等字幕。例如 `电影.mkv` 匹配 `电影.srt`、`电影.zh.srt`；不为匹配字幕反复读取完整目录。
- 字幕面板统一显示内嵌轨道、同目录字幕和“选择本地字幕”，标明当前字幕名称及来源。
- 支持本地和 WebDAV 同目录字幕。远端字幕通过现有 WebDAV 客户端获取到临时副本，保留认证、路径边界和响应大小检查，不将认证信息交给 mpv。
- 同目录只有一个匹配项时可自动加载；存在多个时展示候选，优先建议明确带 `zh`、`chs`、`简体` 等语言标记的中文字幕，标记不明确时让用户选择。提供关闭自动加载的选项。
- 加载过程不暂停视频，显示进度或加载状态并允许取消；失败保留当前字幕且支持重试。确认新字幕加载成功后再清理不再使用的旧副本。
- 重复选择同一字幕时切换到已有轨道，避免重复挂载。切换视频后旧任务不得把字幕加载到新视频中。
- 提供字幕开关，以及“提前 0.5 秒”“延后 0.5 秒”“重置”操作，明确显示当前时间偏移。
- 限制字幕副本容量并检查空间；取消、加载失败和播放器释放时清理临时文件，不删除用户原始字幕。

第二阶段：编码选择和偏好恢复。

- 默认使用播放器支持的自动编码识别，并提供 UTF-8、GB18030、Big5 等手动选择；切换编码时重新加载并保留当前字幕直到成功。
- ASS/SSA 保留样式与格式，避免无条件转码；不承诺自动识别所有编码。
- 按视频来源、路径及版本记住字幕来源、路径、编码和时间偏移，避免不同服务器或不同版本视频共用错误偏好。
- 本地文档仅在获得持久读取授权时保存可恢复引用；权限丢失或字幕被移动、删除、替换时提示重新选择，避免使用过期副本。
- 字号作为次级选项，说明 ASS/SSA 样式字幕与普通文本字幕的调节差异。

验收：覆盖本地及带认证 WebDAV 字幕、中文和特殊字符文件名、多个语言候选、重复选择、取消和重试、快速切换视频、字幕损坏或超限、权限失效、编码乱码和偏移恢复。加载失败不得中断视频或撤掉当前可用字幕；资源释放后无遗留临时副本。

## 实施顺序

1. 核对现有实现，标记已满足项目和差距，确认无需新增重复入口。
2. 优先完成 U02、U12、U04、U06、U07：工具栏按钮、文件操作栏、路径直接跳转、传输详情、错误恢复和媒体默认控件。
3. 完成 U01、U03、U05、U08、U09：位置恢复、确认策略、搜索、图片和统一反馈。
4. 实施 U11 第一阶段，再完成编码选择与偏好恢复；完成 U10，并集中检查横屏、大字体和辅助功能。
5. 全部修改完成后再统一编译和批量验证，修正发现的问题后重新验证受影响范围。
